# Prestashop Gherkin Functionality Summaries

| Gherkin File                          | Functionality Summary                                      |
|---------------------------------------|------------------------------------------------------------|
| 01_AddNewProduct.feature              | Adds a new product to the catalog.                         |
| 02_AddEmptyProduct.feature            | Attempts to add a product with empty fields.               |
| 03_EditProduct.feature                | Edits an existing product's details.                       |
| 04_AddNewState.feature                | Adds a new state to the system.                            |
| 05_AddEmptyState.feature              | Attempts to add a state with empty fields.                 |
| 06_AddNewProductWithTax.feature       | Adds a new product including tax information.              |
| 07_AddNewProductWithTax10.feature     | Adds a new product with a 10% tax rate.                    |
| 08_AddNewFeatures.feature             | Adds new features to a product.                            |
| 09_AddEmptyFeature.feature            | Attempts to add a feature with empty fields.               |
| 10_AddNewAttribute.feature            | Adds a new attribute to a product.                         |
| 11_AddEmptyAttribute.feature          | Attempts to add an attribute with empty fields.            |
| 12_AddNewAddress.feature              | Adds a new address to the system.                          |
| 13_AddEmptyAddress.feature            | Attempts to add an address with empty fields.              |
| 14_AddNewCategory.feature             | Adds a new category to the catalog.                        |
| 15_AddEmptyCategory.feature           | Attempts to add a category with empty fields.              |
| 16_EditCategory.feature               | Edits an existing category's details.                      |
| 17_AddNewManufacturer.feature         | Adds a new manufacturer to the system.                     |
| 18_AddEmptyManufacturer.feature       | Attempts to add a manufacturer with empty fields.          |
| 19_EditManufacturer.feature           | Edits an existing manufacturer's details.                  |
| 20_AddNewSupplier.feature             | Adds a new supplier to the system.                         |
| 21_AddEmptySupplier.feature           | Attempts to add a supplier with empty fields.              |
| 22_RemoveSupplier.feature             | Removes a supplier from the system.                        |
| 23_RegisterEmployee.feature           | Registers a new employee.                                  |
| 24_RegisterEmployee_NoName.feature    | Attempts to register an employee without a name.           |
| 25_RegisterEmployee_NoEmail.feature   | Attempts to register an employee without an email.         |
| 26_RegisterEmployee_NoPassword.feature| Attempts to register an employee without a password.       |
| 27_RegisterEmployee_NoPermission.feature| Attempts to register an employee without permissions.   |
| 28_OutOfStockValidity.feature         | Validates out-of-stock product handling.                   |
| 29_AddTag.feature                     | Adds a new tag to the system.                              |
| 30_AddEmptyTag.feature                | Attempts to add a tag with empty fields.                   |
| 31_AddLanguageIsoCodeValidity.feature | Validates language ISO code handling.                      |
| 32_AddCurrency.feature                | Adds a new currency to the system.                         |
| 33_AddEmptyCurrency.feature           | Attempts to add a currency with empty fields.              |
| 34_EditAddress.feature                | Edits an existing address's details.                       |
| 35_EditEmployee.feature               | Edits an existing employee's details.                      |
